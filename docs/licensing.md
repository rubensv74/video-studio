# Licensing boundary

Video Studio is an orchestration architecture. Every third-party dependency keeps its own license.

Important:

- Motion Canvas packages are published under MIT.
- FFmpeg licensing depends on the build and enabled codecs; verify the actual binary distributed or deployed.
- Remotion uses its own licensing model. Review the current Remotion license before corporate/commercial deployment and before making it an organization-wide standard.

Do not infer that this repository's code license grants rights over its dependencies.
